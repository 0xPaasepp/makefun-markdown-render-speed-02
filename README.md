# Markdown, Built from Scratch

A dependency-free JavaScript renderer that recognizes document blocks before resolving inline syntax, with a small batch runner for directory-based inputs. It matches marked 18.1.3 byte for byte on all 720 practice cases, including the 40 generated documents.
